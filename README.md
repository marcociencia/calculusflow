# ➗ CalculusFlow — Interactive Step-by-Step Math Solver

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)

**Master arithmetic, calculus & algebra with crystal-clear step-by-step solutions**  
Powered by SymPy • 100% free • No API key required

## 🚀 Features

- ✅ **Arithmetic Mastery** — Long addition, subtraction with borrowing, long multiplication & long division with visual “armada” layouts
- 📈 **Limits** — Direct substitution + numerical verification + interactive plots
- 📐 **Derivatives** — Definition by limit, power/product/quotient/chain rules, tangent lines
- ∫ **Integrals** — Riemann sums, indefinite & definite integrals, Fundamental Theorem
- 🧮 **Algebra** — Linear & quadratic equations (Bhaskara), 2×2 and 3×3 linear systems with RREF
- 🎨 **Live plots** — Every solution comes with a clear matplotlib visualization
- 📱 **Fully responsive** — Works perfectly on desktop, tablet and mobile
- 🚀 **One-click deploy** — Ready for Streamlit Community Cloud

## 🛠️ Tech Stack

- **Python 3.9+**
- **Streamlit ≥ 1.30**
- **SymPy ≥ 1.12** (symbolic engine)
- **NumPy + Matplotlib** (plotting)
